# GestaoLaboral 🧪

 Projeto criado em **JAVA** com o objetivo de fixar conceitos importantes da **POO**, com o objetivo de melhorar minha capacidade 
 de pensar em resolução de problemas e agilizar minha velocidade no desenvolvimento de aplicações.



---
## 🎯 Objetivo principal:
 O GestaoLaboral é um projeto desenvolvido em Java com o objetivo de praticar programação orientada a objetos e estruturas de dados. 
 A aplicação permite cadastrar alunos,  equipamentos e empréstimos por meio de um menu interativo. 
 O projeto está em desenvolvimento e será aprimorado conforme avanço nos estudos.


## 📌 Sobre o projeto: 
O **GestaoLaboral** é uma aplicação simples no console visando a organização de cadastros e gerenciamento de alunos, equipamentos 
e controle de empréstimos.

Desenvolvi esse projeto pensando na consolidação de conceitos importantes da programação como uma todo, ou seja, nessa aplicação eu usei conceitos de estrutura de 
dados, organização do código em classes para facilitar a manutenção e entendimento, manipulação das **JAVA Collections**, e implementação de menus interativos tentando
manter o mais intuitivo possível para o usuário.



## ⚙️Funcionalidade: 
- [x] Cadastro de alunos pelo teclado.
- [x] Cadastro de equipamentos.
- [x] Cadastro de empréstimos.
- [x] Menu interativo para gerenciar as ações do sistema.
- [x] Implementação de funcionalidades de busca.
- [ ] Aprimoramento das funcionalidades de listagem e gerenciamento dos registros.
- [ ] Conexão com banco de dados.

Com o passar do tempo pretendo aumentar o leque de funcionalidades mas por hora vou deixar essas duas últimas pois já tenho elas em mente.

## 🧠 Conceitos praticados

Durante o desenvolvimento, são trabalhados conceitos importantes da programação em Java:

- Programação Orientada a Objetos (POO).
- Classes, atributos e métodos.
- Encapsulamento e organização de responsabilidades.
- Collections Framework:
  * ArrayList para armazenar registros.
  * HashSet para organizar equipamentos sem duplicações conforme os critérios de igualdade definidos.
  * HashMap para associar identificadores aos respectivos objetos e facilitar buscas.
- Entrada de dados com Scanner.
- Sobrescrita dos métodos equals() e hashCode().
- Estruturas de controle e menus interativos.
- Controle de versão com Git e GitHub.



## 📂 Principais classes

| Classe              | Responsabilidade                                     |
| ------------------- | ---------------------------------------------------- |
| GestaoLaboralMain | Ponto de entrada da aplicação.                         |
| GerenciadorMenu   | Gerencia o menu principal e o fluxo das ações.         |
| MenuAcoes         | Organiza as operações disponibilizadas pelo menu.      |
| Aluno             | Representa os alunos cadastrados.                      |
| Equipamento       | Representa os equipamentos gerenciados pelo sistema.   |
| Emprestimo        | Representa os empréstimos registrados.                 |
